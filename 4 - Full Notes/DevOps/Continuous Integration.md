## Conceito Geral
É a parte do [[CI CD]] que garante a integração entre o código novo e o código já existente.
Nessa etapa executamos build da aplicação, os testes, analise de qualidade e vulnerabilidades do código e também vulnerabilidades de dependências.
Geralmente após essas etapas é gerada uma release/versão desse software que será a disponibilizada no fim do processo para o ambiente de produção por meio do [[Continuous Delivery]].
