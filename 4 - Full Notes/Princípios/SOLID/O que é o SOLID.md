## Conceito Geral
SOLID é um acrônimo, é um conjunto de 5 princípios da programação orientada a objetos que visam ter um código fácil de ler e manter e que seja mais flexível.
O significado de cada letra é:
**[[Single Responsability Principle]]**: Diz que a classe deve ter apenas um motivo para mudar.
**[[Open-Closed Principle]]**: Uma entidade do software deve estar fechada para modificação, mas aberta para extensão.
**[[Liskov Substitution Principle]]**: Uma classe pode ser substituída por uma classe que herda ela, e o código deve continuar funcionando.
**[[Interface Segregation Principle]]**: Varias interfaces genéricas são melhores do que uma interface de propósito geral.
**[[Dependency Inversion Principle]]**: Dependa de abstrações e não de implementações.
