## Conceito Geral
**Simple Notification Service** é o serviço de notificação da AWS, com ele você pode configurar notificações de praticamente qualquer coisa, por exemplo, custo da conta chegar próximo a um valor determinado, ou indisponibilidade de algum serviço. Por debaixo dos panos, essas notificações funcionam como um sistema de [[O que é uma mensageria|mensageria]].
Essas mensagens pode ser de aplicações para aplicações (A2A) ou de aplicação para pessoa (A2P).
### Tipos de comunicação
- [[Push Notifications]]
- SMS
- Text Message
- EMAIL
- [[HTTP]]
