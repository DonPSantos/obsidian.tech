## Conceito Geral
É um conceito que funciona fora da AWS ou dentro dela, mas a AWS costuma chamar de federação de identidades na Web, nada mais é que você utilizar um login de outro aplicativo, como por exemplo , Google ou Facebook para fazer o login em uma aplicação que você vai criar, isso sem precisar forçar o usuario a criar um usuario só para sua aplicação.
