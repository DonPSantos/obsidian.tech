## Conceito Geral
É uma forma simples de provisionar um web server para sua aplicação, atualmente suporta as principais linguagens como JAVA e .NET. Com ele é possível configurar toda a infra de forma facilitada, ele ti oferece uma tela com opções que você marca ou desmarca e configura [[Load Balancing]], [[Auto Scaling]] e também [[Observability]].
Após configurar pela interface seu web server, basta fazer o upload do zip de sua aplicação, que o Elastic Beanstalk cuida do resto.
