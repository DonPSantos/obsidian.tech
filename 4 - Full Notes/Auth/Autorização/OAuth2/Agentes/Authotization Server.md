## Conceito Geral
Esse é o lugar onde você vai se cadastrar ou já se cadastrou, geralmente são aqueles botões de "Login com Google" onde o próprio Google é um [[Identity Provider|IDP]] ou o [[Identity Provider|IDP]] da aplicação se comunica com o Google para cadastrar o usuário.
Quando você efetua o login nesse Authorization Server é a única etapa onde você vai por suas credenciais e somente ele terá acesso a elas, se a [[Autorização|autorização]] ocorrer com sucesso, será retornado um [[Access Token|access token]] para o [[Client|client]].
