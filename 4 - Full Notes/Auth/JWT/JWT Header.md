## Conceito Geral
O cabeçalho do [[O que é JWT|token JTW]] no geral contém as informações do tipo do token e o algoritmo de criptografia que é utilizado na assinatura.
Exemplo:
``` JSON
{
	"alg": "SHA256",
	"typ": "JWT"
}
```
